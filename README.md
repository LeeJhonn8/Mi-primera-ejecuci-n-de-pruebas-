# Mi primera ejecución de pruebas

## Descripción
Este proyecto consiste en la automatización de pruebas de software sobre el sitio web **Automation Exercise**, utilizando Java y Selenium WebDriver. El objetivo es verificar el funcionamiento de diferentes opciones de la tienda virtual mediante seis casos de prueba.

## Tecnologías utilizadas
- **Java:** lenguaje utilizado para desarrollar las pruebas.
- **Selenium WebDriver:** herramienta para automatizar el navegador.
- **JUnit 5:** utilizado para ejecutar y validar los casos de prueba.
- **Maven:** administración de dependencias.
- **NetBeans:** entorno de desarrollo.
- **GitHub:** almacenamiento y control de versiones del proyecto.

## Patrón de diseño
Se utiliza el patrón **Page Object Model (POM)** para organizar el código y facilitar el mantenimiento de las pruebas.

## Casos de prueba implementados
1. Acceder a la página principal.
2. Consultar la sección de productos.
3. Consultar el detalle de un producto.
4. Buscar un producto.
5. Consultar categorías de productos.
6. Agregar y eliminar productos del carrito.

## Resultados
Se ejecutaron los seis casos de prueba automatizados y se registraron resultados satisfactorios, de acuerdo con las evidencias incluidas en el informe académico.
